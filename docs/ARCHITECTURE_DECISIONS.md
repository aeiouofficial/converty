# Architecture Decision Record Index

- **ADR-001** — Native IExplorerCommand shell integration; no legacy registry-only product path.
- **ADR-002** — Explorer shell code is trigger-only; no conversion/probing/network.
- **ADR-003** — Bridge process between shell DLL and long-lived coordinator.
- **ADR-004** — Coordinator never loads untrusted codec/plugin code.
- **ADR-005** — Disposable worker processes for probe/conversion.
- **ADR-006** — Transactional temp-output + validation + final commit.
- **ADR-007** — Per-family defaults and structured presets; no command strings.
- **ADR-008** — Capability graph/provider architecture for future file families.
- **ADR-009** — Explicit named-pipe security and bounded versioned IPC.
- **ADR-010** — Strict isolation has no silent compatibility downgrade.
- **ADR-011** — Signed/pinned provider supply chain; plugin code only in worker.
- **ADR-012** — Offline/local conversion has network denied by default.
